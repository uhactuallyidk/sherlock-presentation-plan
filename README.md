# Sherlock — แผนพรีเซนต์ 20 สไลด์

คู่มือภาษาไทยสำหรับปรับการนำเสนอ Sherlock ให้เหลือ 20 สไลด์ ภายใน 7 นาที รวมวิดีโอ MVP 45 วินาที

## เอกสาร

- [แผนปรับสไลด์ พร้อมข้อความ layout และบทพูด](SHERLOCK_20_SLIDE_REVISION_PLAN_TH.md)
- [Diagram ก่อนและหลังใช้ Sherlock](SHERLOCK_BEFORE_AFTER_DIAGRAMS_TH.md)

ฉบับปัจจุบันรวม Design Development กับ Service Blueprint ในหน้า 13 พร้อม diagram และวาง Lean Canvas หน้า 17 ก่อน Feasibility หน้า 18–19

Diagram เขียนด้วย Mermaid สามารถอ่านบน GitHub และแก้ข้อความหรือเส้นทางต่อได้

เอกสารเป็นคู่มือปรับงานและแนวคิดบริการ มีข้อเสนอแผนทดสอบและระยะขยาย ไม่ใช่ไฟล์สไลด์หรือวิดีโอ MVP ส่วน PDF ต้นฉบับ แบบสอบถาม ข้อมูลสัมภาษณ์ และสื่ออ้างอิงไม่ได้รวมใน repository นี้

## อัปเดตเอกสาร
